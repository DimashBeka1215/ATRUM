# Atrum Chat (Android)

Зашифрованный мессенджер для двоих через GitHub Gist. Сообщения шифруются AES-256-GCM прямо
на устройстве — в Gist уходит только зашифрованный текст. Никаких серверов, никаких номеров
телефона.

## Как открыть в Android Studio

1. Установи **Android Studio Hedgehog (2023.1.1)** или новее.
2. `File → Open` → выбери папку `GithubChat`.
3. Подожди, пока Gradle подтянет зависимости (5–10 минут в первый раз).
4. Нажми ▶️ Run, выбери эмулятор или подключи телефон по USB (с включённой отладкой).

Если Android Studio предложит обновить Android Gradle Plugin — соглашайся.
Если ругается на `compileSdk = 34` — открой `Tools → SDK Manager` и установи Android 14 (API 34).

## Как пользоваться

### Первый запуск (на обоих телефонах)

1. Заходишь на github.com → Settings → Developer settings → Personal access tokens →
   Tokens (classic) → Generate new token. Дай ему **только** scope `gist`. Скопируй.
2. Заходишь на gist.github.com → создай новый gist:
   - Filename: `chat.txt`
   - Content: любой (можно пробел)
   - Жми **Create secret gist**
3. Скопируй ID гиста из URL (после `/имя_пользователя/` идёт длинная строка hex).
4. В приложении вводи:
   - **GitHub Token** — твой токен
   - **Gist ID** — ID гиста
   - **Ник** — как тебя будут видеть в чате
   - **Пароль** — секретное слово (главное!)
5. Второй человек заходит с **тем же Gist ID и тем же паролем**, но может использовать
   свой токен (или твой). Ник свой.

**Главное правило:** пароль должен совпадать у обоих — иначе сообщения не расшифруются.

## Безопасность

- Токен и пароль хранятся в `EncryptedSharedPreferences` (зашифровано на устройстве).
- GitHub видит только зашифрованный текст, не зная пароля — не расшифрует.
- Если потеряешь пароль, переписку не восстановить.
- Если кто-то получит твой токен — сможет писать/удалять твои gist'ы. Меняй регулярно.

## Совместимость с веб-версией (chat2.html)

Используется тот же алгоритм CryptoJS AES.encrypt (OpenSSL формат с MD5 EVP_BytesToKey).
Сообщения, отправленные из браузера, расшифровываются на телефоне, и наоборот.

## Структура

```
app/src/main/
├── java/com/example/githubchat/
│   ├── MainActivity.kt       — экран логина
│   ├── ChatActivity.kt       — экран чата
│   ├── CryptoHelper.kt       — AES шифрование (CryptoJS-совместимое)
│   ├── GistApi.kt            — работа с GitHub Gist API через OkHttp
│   ├── Message.kt            — модель сообщения
│   └── MessageAdapter.kt     — адаптер RecyclerView
└── res/
    ├── layout/               — XML экранов
    ├── drawable/             — фоны кнопок/полей/сообщений
    └── values/               — цвета, строки, темы
```
